## Changes made

### 1. Added `app.vue`

```vue
<template>
  <NuxtLayout>
    <NuxtPage />
  </NuxtLayout>
</template>
```

This replaces Nuxt's implicit root and follows the Nuxt 3 convention.

### 2. Added `layouts/default.vue`

```vue
<template>
  <slot />
</template>
```

The default layout is a pass-through wrapper, so existing markup is unchanged.

### 3. Consolidated static images

Moved all files from the repo-root `img/` directory into `public/img/`. The root `img/` directory was then deleted.

CSS references such as `/img/BG.svg`, `/img/Dark-bg.svg`, and `/img/Lightmb.svg` continue to resolve correctly from `public/img/`.

### 4. Updated `.gitignore`

Added `.data/` to `.gitignore` so the SQLite cache generated by `@nuxt/content` is not committed.
